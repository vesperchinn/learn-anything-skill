# Project Patterns (Skill Quick Ref)

Canonical version: `references/project-patterns.md`

## Five Patterns

| Pattern | For | Example |
|---------|-----|---------|
| **Build a Tool** | Technical domains | A working mini-app or script |
| **Create a Framework** | Conceptual domains | A playbook, template, or decision tree |
| **Produce Content** | Knowledge domains | A comprehensive article, guide, or analysis |
| **Analyze Data** | Research domains | A dataset analysis with visualizations |
| **Design a System** | Engineering domains | An architecture doc with trade-off analysis |

## Project Sizing

`scope = (daily_time_hours × 7 days) × 0.7`

## Quality Checklist
- Every must-learn concept is exercised
- Top 3 weak points from progress.md are addressed
- Each day has a verifiable deliverable
- Final result is demonstrable in ≤ 5 minutes
