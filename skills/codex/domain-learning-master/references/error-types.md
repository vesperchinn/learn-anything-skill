# Error Type Reference (Skill Quick Ref)

Canonical version: `references/error-types.md`

## Four Error Types

| Type | Signal | Fix |
|------|--------|-----|
| **concept-gap** | Can't define the concept | Return to definition + Feynman analogy |
| **application-failure** | Can define but can't use | Worked example → near-identical imitation → gradual variation |
| **expression-unclear** | Understands but can't articulate | Explain to a 12-year-old, use concrete analogy, write it down |
| **knowledge-confusion** | Mixes up Concept A and B | Side-by-side comparison table + discrimination exercise |

## Diagnostic Decision Tree

```
Error → Can they define it? NO → concept-gap
                    YES → Can they apply it? NO → application-failure
                                        YES → Can they explain it? NO → expression-unclear
                                                            YES → Confusing with another? YES → knowledge-confusion
```
