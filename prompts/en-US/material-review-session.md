# Material Review Session

**Mode**: Material-Grounded Learning
**Inputs**: `progress.md`, `learning_materials/material_index.md`, `learning_materials/material_learning_plan.md`, relevant extracted material
**Output files**: daily review, progress updates, optional flashcard

---

Run a daily learning session grounded in the user's materials.

## Session Structure

1. Review previous material sections.
2. Teach up to 3 concepts from the assigned material sections.
3. Show examples from the material first.
4. Ask 5 questions grounded in the material.
5. Assign one deliverable task connected to the material.
6. Update progress and coverage.

## Grounding Requirements

- Every concept must list the material ID and page, slide, or section when known.
- If a location is unknown, write `location unresolved`.
- If you add outside context, label it `Supplemental`.
- If a table, chart, screenshot, diagram, or flowchart is involved, identify it explicitly.
- Do not invent details that are not in the material.

## If Extraction Is Incomplete

- Teach only what is available.
- Mark affected sections as `Partially grounded`.
- Add follow-up items to `learning_materials/extraction_issues.md`.
