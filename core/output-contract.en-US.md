# Output Contract

Every platform adapter must satisfy this output contract.

## Daily learning session

Must include:

1. Today's theme
2. Three concepts, each with a one-line explanation, analogy, technical explanation, real case, and common pitfall
3. Five practice questions without answers shown up front
4. One checkable deliverable task
5. Acceptance criteria
6. Source records or unverified notes
7. Review and next steps

## Stage test

Must include:

- 10 multiple-choice questions
- 5 concept explanation questions
- 3 scenario application questions
- 1 integration task
- 100 total points
- Answers and grading rubric kept separate until the user submits answers

## Material-grounded output

Must include:

- Material manifest
- Material index
- Material location or ID for each module
- `Grounded` / `Partially grounded` / `Supplemental` labels
- Records for unreadable content

## Reliability output

Must include:

- Source Notes
- Freshness Risk
- Claims to Verify
- Last Verified
- Recommended Review Interval

## No-file-write output

Use this format:

````markdown
### Save as: learn-{domain_slug}/path/to/file.md
```markdown
file content
```
````
