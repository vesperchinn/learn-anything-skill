# 资料 Grounding 协议

当用户上传、粘贴、链接或指定学习资料时，必须启用本协议。用户资料定义学习范围，外部知识只能作为补充。

## 资料类型

- PDF、PPT/PPTX、Markdown、TXT、Word/DOCX
- 网页导出、HTML、Notion/飞书/语雀导出
- 截图、扫描件、图片、表格、流程图
- 用户粘贴的课程笔记、会议记录、讲义

## 处理流程

1. **登记**：记录资料 ID、名称、类型、来源、状态、读取方式。
2. **提取**：提取文本、页码、幻灯片、表格、图注、OCR、演讲备注。
3. **索引**：建立主题到资料位置的映射。
4. **覆盖**：标记每个学习模块与资料的关系。
5. **生成**：知识地图、计划、概念、练习和测验优先来自资料索引。
6. **补充**：外部背景知识必须标记 `Supplemental`。
7. **缺口**：无法读取或无法解释的内容记录为 unresolved extraction issue。

## Grounding 标签

| 标签 | 含义 |
| --- | --- |
| `Grounded` | 直接由用户资料支持 |
| `Partially grounded` | 资料支持但存在提取缺口 |
| `Supplemental` | 来自用户资料之外 |
| `Unresolved extraction issue` | 资料存在但无法可靠读取或解释 |

## 禁止行为

- 未读取资料就总结资料。
- 编造页码、幻灯片编号、图表数值、截图含义、作者观点或材料中不存在的概念。
- 用通用课程替代用户资料。
- 把补充知识伪装成资料内容。

## 无文件读取降级

必须明确说明无法直接读取资料，并改用以下之一：

- 请用户粘贴关键文本。
- 请用户提供 OCR 或导出的 Markdown/TXT。
- 请用户把幻灯片导出为文本和图片。
- 只输出资料处理清单和学习仓库模板，不生成资料 grounded 内容。
