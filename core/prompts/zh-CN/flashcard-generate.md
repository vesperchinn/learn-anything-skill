# 生成闪卡

**阶段**: 3 — 日常循环（复盘之后）
**输入**: 今日概念 + progress.md 中的今日错误
**需要上下文**: 今日概念文件 + progress.md 中的薄弱点
**典型 token 数**: ~2,500

---

你是一名领域学习工程师。将今天的学习内容压缩为一张知识压缩卡片。

## 输入

- 今日的 3 个概念（来自 `01_core_concepts/`）
- 今日的错误（来自 progress.md 的薄弱点部分）

## 卡片格式

保存到 `05_flashcards/day-{day_number}.md`：

```markdown
# 第 {day_number} 天 — {日期}

## 一句话总结
{今天学习内容的概括}

## 5 个关键词
1. {关键词} — {一句话定义}
2. ...
3. ...
4. ...
5. ...

## 3 个应用场景
1. {今日知识能实际应用的场景}
2. ...
3. ...

## 2 个常见误区
1. ❌ {错误} → ✅ {纠正}
2. ❌ {错误} → ✅ {纠正}

## 1 个经典案例
{今天最有启发性的真实案例}

## 自测题
{一道测试今天最重要概念的题目}

## 与之前知识的关联
- 关联到第 X 天：{今日概念与之前内容的关系}

## 最可能忘记的内容
{基于今天的错误和薄弱点}

## 下次复习
建议复习日期：{日期，基于间隔重复——1 天、3 天、7 天、30 天}

---

### 来源注释 (Source Notes)
- {来源描述} - [已验证] 或 [未验证]

### 时效性风险 (Freshness Risk)：🟢 稳定 / 🟡 演变中 / 🔴 易变

### 待验证主张 (Claims to Verify)
- [ ] {主张} - 建议验证方式：{method}

**最后验证日期 (Last Verified)**：{date 或 "尚未验证"}
**建议复查间隔 (Recommended Review Interval)**：{interval}
```

不得伪造来源、URL、日期、论文、官方文档或 benchmark。无法联网时，将事实主张标记为 `[未验证]`，并写入 `09_sources/claims_to_verify.md`。

## 间隔重复计划
- 第 1 天：复习明日 5 个关键要点
- 第 3 天：重读本卡片
- 第 7 天：重做自测题
- 第 30 天：结课前的最终复习

所有输出使用 {learning_language}。写入 `05_flashcards/`。
