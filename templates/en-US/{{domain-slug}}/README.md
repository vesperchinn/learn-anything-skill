# Learn {{domain}}

This is a structured learning repository for mastering **{{domain}}**, generated by the [Learn Anything Skill Pack](https://github.com/vionlabs/learn-anything-skill).

## How to Use This Repository

This repository is designed to be used with an AI agent (Codex, Claude Code, Cursor, etc.) acting as your personal domain learning engineer.

### Daily Routine

1. Start in the agent chat. You do not need to open every file first.
2. Use `TODAY.md` as today's single entry point.
3. Let the agent explain today's goal, concepts, and small task in the chat.
4. Complete the answer template and send it back to the agent.
5. The agent checks your answer, updates `progress.md`, and writes the review.

### Learning Principles

- **Big picture first, then details** — Always understand the landscape before diving into specifics
- **Learn -> Practice -> Output -> Test** — Every day cycles through all four modes
- **20-60-20 rule** — Focus on the critical 20% first, skip the middle 60%, save advanced 20% for later
- **Minimum viable project** — The goal is to build something real, not just read about it

### Guided Learning Mode

After this repository is created, the agent should immediately start Day 1 in
the chat. You do not need to open a stack of Markdown files first. The agent
will give today's goal, explain 2-3 concepts, assign one small task, provide a
copyable answer template, check your reply, and update `progress.md`.

If you only want files and no guided session, say `scaffold only` or `generate
files only`.

### Knowledge Reliability

- `09_sources/sources.md` records sources used across the repository.
- `09_sources/source_quality_policy.md` defines source tiers and no-fabrication rules.
- `09_sources/claim_ledger.md` tracks factual claims and their verification status.
- `09_sources/claims_to_verify.md` lists claims that still need authoritative checking.
- `09_sources/freshness_log.md` tracks freshness risk and review dates.

If an AI agent cannot access the web, treat newly generated content as an **Unverified Draft** and verify important claims before relying on them.

### Learn From Your Own Materials

Place PDFs, slide decks, Markdown, TXT, Word docs, or webpage exports in
`learning_materials/raw/`. The AI agent should extract readable content into
`learning_materials/extracted/`, build `material_index.md`, and generate the
knowledge map and plan from those materials first. Any outside explanation must
be marked `Supplemental`, and unreadable content belongs in
`learning_materials/extraction_issues.md`.

### Tracking Progress

- `progress.md` is your dashboard — check it daily to see where you stand
- `progress-log.md` is the complete, append-only history — refer to it for the full journey
- Stage tests happen every 7 days — they are your reality check and course-correction point
