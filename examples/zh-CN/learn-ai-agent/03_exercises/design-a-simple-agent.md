# 练习：设计一个简单的 Agent

## 任务
设计一个"每日新闻简报 Agent"，它收集每日头条新闻并在每天早上通过邮件发送摘要。

## 要求
1. 用一句话定义 Agent 的目标
2. 列出它需要的工具（3-5个）
3. 定义每个工具的 schema（名称、描述、参数）
4. 画出典型早间执行流程的 ReAct 循环
5. 定义输出格式（邮件长什么样）
6. 列出 3 个可能出错的地方以及 Agent 应如何处理

## 验收标准
- [ ] 目标具体且可衡量
- [ ] 每个工具都有清晰的 schema，包含参数类型
- [ ] ReAct 循环覆盖：思考 → 行动 → 观察 → 决策（继续/结束）
- [ ] 输出格式完整（主题、正文结构）
- [ ] 错误处理覆盖：API 失败、无新闻、邮件发送失败

## 参考答案（部分 —— 供你尝试后参考）

### 目标
每天早上 8:00 自动收集过去 24 小时内 AI 领域的 Top 5 新闻，生成摘要，发送邮件到用户邮箱。

### 工具
1. `search_news(query, hours=24, limit=10)` — 搜索近期新闻
2. `summarize(text, max_length=200)` — 将新闻正文压缩为摘要
3. `send_email(to, subject, body)` — 发送邮件
4. `log_result(status, details)` — 记录执行日志

### ReAct 循环
```
思考: "需要今天的 AI 新闻" → search_news("AI news", 24h)
观察: 获取到 10 篇文章
思考: "摘要 Top 5" → summarize(文章) × 5
观察: 获得 5 条摘要
思考: "准备发送" → send_email(用户, "AI 每日简报", 摘要)
观察: 邮件发送成功 → 完成
```
