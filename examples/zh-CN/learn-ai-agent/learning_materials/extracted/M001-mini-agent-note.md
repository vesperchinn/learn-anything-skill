## 第 1 节：Agent 定义

AI agent 是一种软件系统。它会根据目标、当前上下文和可用工具，决定下一步应该采取什么行动。

## 第 2 节：基础循环

1. 观察目标和当前状态。
2. 规划下一步有用行动。
3. 通过回答、调用工具、编辑文件或询问缺失信息来行动。
4. 检查结果，并判断是否需要继续下一步。

## 第 3 节：工具使用与诚实边界

工具使用让 agent 可以处理文件、计算器、搜索工具、浏览器或 API。Agent 不应假装自己使用了工具或读取了文件。
