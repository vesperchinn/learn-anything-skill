# Concept 02: Agent Architecture

## 一句话解释
Agent 的架构由四个核心组件组成——大脑（LLM）、记忆（Memory）、工具（Tools）和规划器（Planner）——它们协同工作让 Agent 能自主完成任务。

## 生活类比
想象你要做一顿从未做过的菜：
- **大脑（LLM）**：你的思考能力——理解菜谱、判断火候
- **记忆（Memory）**：你记得以前做类似菜的经验、知道盐在哪里
- **工具（Tools）**：锅、刀、炉灶——你能操作的物品
- **规划器（Planner）**：你心里的做菜步骤——先备菜、再热锅、再炒、最后调味

缺任何一个，你都做不出这道菜。

## 技术解释

```
┌──────────────────────────────────────┐
│              AGENT                    │
│  ┌──────────┐  ┌──────────────────┐  │
│  │  LLM     │  │    Planner       │  │
│  │ (Reason) │  │ (Decompose goal) │  │
│  └────┬─────┘  └────────┬─────────┘  │
│       │                 │            │
│  ┌────┴─────────────────┴──────┐     │
│  │        Orchestrator         │     │
│  │   (Think→Act→Observe Loop)  │     │
│  └────┬─────────────────┬──────┘     │
│       │                 │            │
│  ┌────┴─────┐   ┌───────┴──────┐     │
│  │  Memory  │   │    Tools     │     │
│  │ Short/Long│  │ Search/Code/ │     │
│  │          │   │ API/Browser  │     │
│  └──────────┘   └──────────────┘     │
└──────────────────────────────────────┘
```

**LLM**：推理引擎，负责理解、决策、生成  
**Planner**：将复杂目标分解为子任务序列  
**Memory**：短期 = 对话上下文窗口；长期 = 向量数据库/知识库  
**Tools**：Agent 可以操作的外部能力（搜索、代码执行、API 调用、浏览器）  
**Orchestrator**：管理 Think→Act→Observe 循环

## 真实案例

**Claude Code** 的架构就是一个典型的 Agent：
- LLM = Claude (大脑)
- Tools = 文件读写、Shell 执行、Web 搜索
- Memory = 对话上下文 + CLAUDE.md 项目规则
- Planner = 内置的任务分解能力

当你要求 Claude Code "修复这个 bug"，它自己读代码→定位问题→改文件→运行测试→检查结果。

## 常见误区
❌ 以为加一个 LLM 就等于有了 Agent  
✅ Agent 需要 LLM + Memory + Tools + Planner 四个组件协同工作

## 练习
画出你手机上一个 app 的「Agent 架构」——它的 LLM 是什么？它的 Tools 有哪些？它的 Memory 存在哪里？
