# Concept 01: What is an AI Agent?

## 一句话解释
AI Agent 是一个能感知环境、自主制定计划、执行动作、并基于反馈自我纠正的智能系统——它不是只会回答问题，而是能独立完成多步骤任务。

## 生活类比
一个 AI Agent 就像一个配了电脑和权限的聪明实习生：
- 你给他一个目标（"帮我做竞品调研"）
- 他自己拆解任务（搜索→整理→对比→写报告）
- 他自己调用工具（搜索引擎、文档、Excel）
- 他遇到问题自己想办法（搜不到就换关键词，数据矛盾就交叉验证）
- 他做完后交给你结果，并解释他是怎么做的

普通 AI 只能回答「怎么做竞品调研」，Agent 能直接帮你做完。

## 技术解释

```
Agent = LLM (大脑) + Tools (手脚) + Memory (记忆) + Planning (规划能力)
```

核心循环（ReAct 模式）：
1. **Think**: Agent 分析当前状态，思考下一步做什么
2. **Act**: 执行一个工具调用或输出
3. **Observe**: 观察执行结果
4. **Repeat**: 根据观察调整计划，继续循环

关键区别于传统程序：
- 传统程序：规则预先定义，路径固定
- Agent：目标驱动，路径动态生成，失败后自己找替代方案

## 真实案例

**Auto-GPT** (2023)：第一个引起广泛关注的开源自主 Agent。给定目标"帮我做市场调研并写报告"，它会自动：
1. 搜索相关市场数据
2. 整理和对比信息
3. 发现缺失信息后自动补充搜索
4. 生成结构化报告
5. 自己检查报告质量并修改

效果参差不齐（GPT-3.5 时代），但它清晰地展示了 Agent 范式。

## 常见误区
❌ 以为 Agent 就是「有性格的聊天机器人」  
✅ Agent 的核心不是聊天，而是**自主完成任务的循环能力**（Think → Act → Observe → Repeat）
