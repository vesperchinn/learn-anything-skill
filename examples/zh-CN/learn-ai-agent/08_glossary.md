# Glossary — AI Agent

| Term | Definition | First Encountered |
|------|-----------|-------------------|
| **Agent** | 能感知环境、自主制定计划、执行动作并基于反馈自我纠正的智能系统 | Day 1 |
| **LLM (Large Language Model)** | 大语言模型，Agent 的推理引擎 | Day 1 |
| **ReAct** | Reasoning + Acting：思考→行动→观察→思考的循环模式 | Day 4 |
| **Tool Use / Function Calling** | Agent 调用外部工具的能力 | Day 5 |
| **Prompt** | 给 LLM 的指令文本，定义其行为边界 | Day 2 |
| **Chain-of-Thought (CoT)** | 让 LLM 逐步推理而非直接给出答案的提示技巧 | Day 3 |
| **Memory (Short-term)** | 对话上下文窗口内的临时记忆 | Day 8 |
| **Memory (Long-term)** | 持久化存储的知识（向量库、数据库） | Day 9 |
| **RAG (Retrieval-Augmented Generation)** | 检索增强生成：从外部知识库检索相关信息再回答 | Day 15 |
| **Embedding** | 将文本转换为数字向量以计算语义相似度 | Day 15 |
| **Vector Database** | 存储和检索语义向量的数据库 | Day 16 |
| **Planning** | 将复杂目标分解为可执行步骤 | Day 11 |
| **Orchestration** | 管理和调度多个 Agent/Tool 的框架 | Day 22 |
| **Guardrails** | Agent 的安全护栏——防止越权和有害输出 | Day 23 |
| **Human-in-the-Loop** | Agent 在关键节点暂停等待人类确认 | Day 23 |
| **Multi-Agent System** | 多个 Agent 分工协作完成复杂任务 | Day 22 |
