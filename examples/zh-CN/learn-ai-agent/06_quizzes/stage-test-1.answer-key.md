## Section B: 概念解释 — 评分标准（每题 6 分）

| Q | 评分标准 |
|---|----------|
| Q11 | 2分 定义 + 2分 类比 + 2分 与 LLM 的区别 |
| Q12 | 每个组件 1.5 分（角色 0.5 + 解释 0.5 + 示例 0.5） |
| Q13 | 2分 步骤解释 + 2分 停止条件 + 2分 实例演示 |
| Q14 | 2分 为什么需要工具 + 2分 schema 的作用 + 2分 不使用工具的场景 |
| Q15 | 各 1 分定义 + 2分 使用时机 + 2分 示例 |

## Section C: 场景应用 — 评分标准（每题 10 分）

| Q | 评分标准 |
|---|----------|
| Q16 | 3分 工具/schema + 3分 ReAct 循环 + 4分 错误处理 |
| Q17 | 3分 故障诊断 + 3分 正确行为 + 4分 prompt 修正 |
| Q18 | 每题 3 分（选择 1 分 + 推理 2 分）|

## Section D: 综合项目（20 分）

- 4 分 架构图
- 4 分 工具 schema
- 4 分 ReAct 流程演示
- 4 分 错误处理（3 种场景）
- 4 分 改进建议

## 及格线

- **通过**: ≥ 70 / 100
- **未通过（< 70）**: 生成 3 个针对性补救练习，重新规划未来 3 天，安排 3 天后补考
- **边缘（65–69）**: 让学习者选择补考还是带着必做薄弱点练习继续前进

## 按错误类型的补救策略

| 错误标签 | 补救策略 |
|----------|----------|
| `[concept-gap]` | 回到概念定义。用更简单的类比重新解释。做 3 道回忆题。 |
| `[application-failure]` | 给出完整示例 → 近似场景模仿 → 逐步增加变化。 |
| `[expression-unclear]` | 要求向 12 岁孩子解释。要求使用具体类比。要求写下来。 |
| `[knowledge-confusion]` | 并排对比表 + 5 个案例区分练习（判断属于 X 还是 Y）。 |
