## 第三部分：场景应用（3 × 10 = 30 分）

### 第 16 题 — 设计一个 Agent
一家创业公司想构建一个处理退款请求的"客服 Agent"。Agent 必须：验证订单是否存在、检查退款政策、处理退款、发送确认邮件。

设计这个 Agent：(a) 列出需要的工具及其 Schema，(b) 画出典型退款请求的 ReAct 循环，(c) 指出 2 个可能出错的地方以及 Agent 应如何处理。

### 第 17 题 — 诊断失败原因
一个 Agent 被赋予了"找到 1000 元以下最好的笔记本电脑"这个目标。它只搜索了一次网页，获得了 50 条结果，然后立即把第一条结果输出为"最好的"。哪里出了问题？解释：(a) ReAct 循环的哪个环节失败了，(b) Agent 应该怎么做才正确，(c) 如何修改 System Prompt 来防止这个问题。

### 第 18 题 — 选择正确的模式
对以下每个任务，判断 CoT 还是 ReAct 更合适并说明原因：
- (a) 逐步解决一个复杂的数学题
- (b) 找到并预订从北京到东京最便宜的航班
- (c) 写一首李白风格的诗

## 第四部分：综合项目（1 × 20 = 20 分）

### 第 19 题 — 构建一个研究简报 Agent

设计一个"每日科技新闻简报 Agent"，它：
1. 每天早上 8 点搜索 Top 5 科技新闻
2. 用 2-3 句话总结每篇文章
3. 组装一份简报邮件，包含主题行、摘要和来源链接
4. 将邮件发送给用户

你的设计必须包括：
- (a) Agent 架构图（4 个组件 + 数据流）
- (b) 工具列表，包含完整的 Schema（名称、描述、参数）
- (c) 典型早间执行的 ReAct 循环走查
- (d) 错误处理：搜索 API 宕机怎么办？没有新闻怎么办？邮件发送失败怎么办？
- (e) 使用一周后你会做的一项改进
