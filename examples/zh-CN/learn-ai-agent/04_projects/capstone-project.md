# 毕业项目：个人研究助手 Agent

## 项目概述

**项目名称**: ResearchPal — 个人研究助手 Agent

**一句话介绍**: 输入一个研究主题，Agent 自动搜索、整理、对比信息，生成一份带引用的结构化研究报告。

**核心功能**:
1. 接收研究主题并拆解为子问题
2. 自动搜索多个来源（网页 + 学术数据库）
3. 对搜索结果进行去重、排序和相关性过滤
4. 生成结构化报告（摘要 + 关键发现 + 对比表 + 引用列表）
5. 支持用户追问和深度展开

**技术栈**: Python + OpenAI API + SerpAPI（搜索）+ Markdown 文件输出
