# 第 1 天 — 2026-06-11

## 一句话总结
AI Agent 是能自主完成多步骤任务的智能系统，区别于只会一问一答的普通 LLM。

## 5 个关键词
1. **Agent** — 能感知、规划、执行、自我纠错的自主系统
2. **LLM** — Agent 的推理引擎（大脑），负责理解和生成
3. **自主性** — Agent 在无人类干预下做出决策并执行的能力
4. **目标驱动** — Agent 从目标出发反推步骤，而非按固定规则执行
5. **思考-行动-观察** — Agent 的核心循环：思考→行动→观察→调整

## 3 个应用场景
1. 自动客服 Agent：理解用户问题 → 查询订单系统 → 执行退款 → 发送确认邮件
2. 代码审查 Agent：读取 PR diff → 检查代码规范 → 运行测试 → 生成 review 意见
3. 个人助理 Agent：接收「帮我规划下周旅行」→ 搜索航班酒店 → 对比价格 → 生成行程表

## 2 个常见误区
1. ❌ 以为 Agent = 有性格的聊天机器人 → ✅ Agent 的核心不是聊天，而是自主完成任务循环
2. ❌ 以为 Agent 能完美执行任何任务 → ✅ 当前 Agent 仍在早期阶段，复杂任务需要 Human-in-the-loop

## 1 个经典案例
**Auto-GPT**（2023）— 第一个开源自主 Agent。给定「帮我做 EV 市场调研」，它自动搜索、整理、对比数据，生成结构化报告，并在发现信息缺失时自我纠错。展示了 Agent 范式的全部潜力——也暴露了早期 Agent 无限循环、token 消耗巨大等问题。
