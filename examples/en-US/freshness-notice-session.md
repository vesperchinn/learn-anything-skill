## Today, learn just one sentence first

An API is a way for one program to ask another service to do something using a structured request.

## Put it into your real situation

For the OpenAI API, your program sends a request with instructions and receives a response it can use in an app, document workflow, or learning tool.

## I do

A beginner-friendly mental model:

1. Your app prepares a request.
2. The API receives it.
3. The service returns a response.
4. Your app decides what to do with that response.

## Look at a bad example

"The API is the AI."

This is hard to use because it mixes the doorway with the service behind it.

## Now look at a better example

"The API is the doorway my app uses to send a task to the AI service and receive a result."
