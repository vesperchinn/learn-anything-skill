## 1. What Problem Does This Field Solve?

AI Agent solves a fundamental problem: **how to make AI not just answer questions, but autonomously complete complex multi-step tasks**. Without agent technology, large language models can only do Q&A — you ask, they answer. With agents, AI can make its own plans, call tools, remember context, and self-correct when things go wrong — like a real digital assistant getting work done independently.

## 2. Feynman Explanation

Imagine you have a brilliant intern who has never left their desk. You can ask them any question, and they can find the answer in a book — but they cannot book a flight, organize your inbox, or do market research on their own. Now give that intern a laptop, internet access, a phone, and teach them: "when you don't know, look it up first; when you make a mistake, try a different approach; and when you're done, double-check your work." That upgraded intern is an AI Agent.

## 5. Top 10 Confusion Pairs

| # | Concept A | Concept B | Key Difference |
|---|-----------|-----------|----------------|
| 1 | Agent | LLM | LLM is the brain; Agent is the whole body (brain + memory + tools + action) |
| 2 | RAG | Fine-tuning | RAG looks up references (external knowledge); fine-tuning memorizes (internal knowledge) |
| 3 | Tool Use | Function Calling | Function Calling is the implementation; Tool Use is the broader concept |
| 4 | ReAct | Chain-of-Thought | CoT is a thinking pattern; ReAct is thinking + acting + observing as a complete loop |
| 5 | Memory | Context | Context is short-term (conversation window); Memory is a long-term storage system |
| 6 | Multi-Agent | Orchestration | Multi-Agent defines roles; Orchestration is the scheduling mechanism |
| 7 | Agent | Workflow | Workflow is a fixed process; Agent makes dynamic decisions |
| 8 | Embedding | Vector DB | Embedding is the conversion method; Vector DB is the storage tool |
| 9 | Autonomous Agent | Human-in-the-Loop | Fully autonomous vs. human confirmation at key decisions |
| 10 | Guardrails | Prompt | Prompt defines behavior; Guardrails constrain behavior boundaries |

## 6. Five Learning Stages

| Stage | After Completing | Deliverable | Days |
|-------|-----------------|-------------|------|
| **1: Foundation** | Understand what an Agent is, why it matters, and the core loop | Write a beginner-friendly Agent explainer post | 1-6 |
| **2: Tools & Memory** | Can make an Agent use tools and leverage memory | Hand-write a ReAct Agent in pseudocode | 7-13 |
| **3: Knowledge & Retrieval** | Understand RAG, vector stores, and knowledge injection | Build a simple RAG Q&A system | 14-20 |
| **4: Multi-Agent & Safety** | Understand multi-agent collaboration and safety | Design a two-agent collaboration scheme | 21-25 |
| **5: Capstone Project** | Independently build a working Agent project | Personal Research Assistant Agent | 26-30 |

## 7. The 20-60-20 Split

### Must-Learn-Now (20%)
Agent definition, LLM basics, ReAct loop, Tool/Function Calling, Prompt engineering, Chain-of-Thought, Memory (fundamentals)

### Skip-for-Now (60%)
Specific framework API details, complex multi-agent coordination patterns, Vector DB implementation internals, agent protocol specifications, performance optimization tricks

### Learn-Later (20%)
Fine-tuning LLMs for agent use, custom orchestration frameworks, agent security auditing, production deployment, A2A/MCP protocol implementations

## 8. Minimum Viable Knowledge

To build a working Agent, you only need these 8 things:
1. What an Agent is
2. Basic LLM usage (API calls)
3. Prompt writing (System Prompt + User Prompt)
4. Function Calling (at least one tool)
5. ReAct loop logic
6. Simple Memory (conversation history storage)
7. Basic error handling
8. A working demo

## 9. What NOT to Learn Yet

- X LangChain/LlamaIndex full API surface (understand principles first, frameworks later)
- X Comparing every agent framework (Auto-GPT vs CrewAI vs LangGraph)
- X Vector DB indexing algorithms (HNSW internals)
- X MCP/A2A protocol specifications
- X Production agent deployment (Docker, K8s, monitoring)
- X Custom Fine-tuning
- X Multi-agent game theory
