## Section D: Integration Project (20 points)

- 4pts architecture diagram

- 4pts improvement suggestion

## Pass Threshold

- **Pass**: ≥ 70 / 100
- **Fail (< 70)**: Generate 3 targeted remedial exercises, re-plan the next
  3 days, schedule a re-test in 3 days.
- **Borderline (65–69)**: Offer the learner a choice between a re-test or
  proceeding with mandatory weak-point exercises.

## Remediation by Error Type

| Error tag | Remediation strategy |
|-----------|---------------------|
| `[concept-gap]` | Return to the concept definition. Re-explain with a simpler analogy. 3 recall questions. |
| `[application-failure]` | Worked example → near-identical scenario → gradually increase variation. |
| `[expression-unclear]` | Ask learner to explain to a 12-year-old. Require a concrete analogy. Have them write it down. |
| `[knowledge-confusion]` | Side-by-side comparison table + 5-case discrimination exercise (classify each as X or Y). |
