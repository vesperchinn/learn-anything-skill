# Recommended Resources -- AI Agent

## Getting Started

- **Lilian Weng's Blog**: "LLM Powered Autonomous Agents" -- The most influential technical blog post in the agent space
- **Anthropic's Agent Docs**: "Building effective agents" -- Best practices straight from a team shipping production agents
- **DeepLearning.AI Short Courses**: "AI Agentic Design Patterns with AutoGen"
- **OpenAI Cookbook**: "How to build an agent with the OpenAI API" -- Practical code examples for function calling
- **Simon Willison's Blog**: Excellent practical guides on prompt engineering and tool use

## Advanced Resources

- **Paper**: "ReAct: Synergizing Reasoning and Acting in Language Models" (Yao et al., 2023)
- **Paper**: "Toolformer: Language Models Can Teach Themselves to Use Tools" (Schick et al., 2023)
- **Paper**: "WebGPT: Browser-assisted question-answering with human feedback" (OpenAI, 2021)
- **Open Source**: LangGraph, CrewAI, AutoGen, OpenAI Agents SDK

## Tools & Community

- **LangChain**: Agent development framework (beginner-friendly)
- **OpenAI Agents SDK**: Build agents directly using the OpenAI API
- **r/LocalLLaMA**: Reddit community discussing open-source agent implementations
- **@LangChainAI**: X/Twitter for agent development news and updates
- **Hugging Face Agents**: Open-source agent library integrated with the Hugging Face ecosystem
- **Anthropic Console**: Tool for prototyping and evaluating agent prompts
