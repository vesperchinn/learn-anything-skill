# Glossary -- AI Agent

| Term | Definition | First Encountered |
|------|-----------|-------------------|
| **Agent** | An intelligent system that perceives its environment, autonomously plans, executes actions, and self-corrects based on feedback | Day 1 |
| **LLM (Large Language Model)** | A large language model that serves as the Agent's reasoning engine | Day 1 |
| **ReAct** | Reasoning + Acting: a loop pattern of Think -> Act -> Observe -> Think | Day 4 |
| **Tool Use / Function Calling** | The Agent's ability to call external tools | Day 5 |
| **Prompt** | Instructions given to the LLM that define its behavior boundaries | Day 2 |
| **Chain-of-Thought (CoT)** | A prompting technique that makes the LLM reason step-by-step rather than jumping to an answer | Day 3 |
| **Memory (Short-term)** | Temporary memory within the conversation context window | Day 8 |
| **Memory (Long-term)** | Persistently stored knowledge (vector stores, databases) | Day 9 |
| **RAG (Retrieval-Augmented Generation)** | Retrieving relevant information from an external knowledge base before generating an answer | Day 15 |
| **Embedding** | Converting text into numerical vectors to compute semantic similarity | Day 15 |
| **Vector Database** | A database that stores and retrieves semantic vectors | Day 16 |
| **Planning** | Breaking down a complex goal into executable steps | Day 11 |
| **Orchestration** | A framework for managing and coordinating multiple agents/tools | Day 22 |
| **Guardrails** | Safety barriers for agents that prevent unauthorized actions and harmful output | Day 23 |
| **Human-in-the-Loop** | The agent pauses at key decision points for human confirmation | Day 23 |
| **Multi-Agent System** | Multiple agents working together on different parts of a complex task | Day 22 |
