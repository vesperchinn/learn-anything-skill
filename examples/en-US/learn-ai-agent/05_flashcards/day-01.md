## One-line Summary
An AI Agent is an intelligent system that autonomously completes multi-step tasks, unlike a regular LLM that can only answer questions one at a time.

## 5 Keywords
1. **Agent** -- An autonomous system that perceives, plans, acts, and self-corrects
2. **LLM** -- The Agent's reasoning engine (brain), responsible for understanding and generating
3. **Autonomy** -- The ability to make decisions and act without human intervention
4. **Goal-driven** -- Starting from a goal and working backward through steps, rather than following fixed rules
5. **Think-Act-Observe** -- The Agent's core loop: think -> act -> observe -> adjust

## 3 Application Scenarios
1. Customer support Agent: understand the issue -> look up the order -> process a refund -> send confirmation email
2. Code review Agent: read the PR diff -> check code style -> run tests -> generate review comments
3. Personal assistant Agent: receive "plan my next week's trip" -> search flights and hotels -> compare prices -> generate itinerary

## 2 Common Pitfalls
1. X Mistaking an Agent for "a chatbot with personality" -> Y The core of an Agent is not conversation, it's the autonomous task completion loop
2. X Assuming Agents can perfectly execute any task -> Y Current agents are still early-stage; complex tasks need human-in-the-loop

## 1 Classic Case
**Auto-GPT** (2023) -- The first open-source autonomous agent. Given "do EV market research," it automatically searched, organized, compared data, generated a structured report, and self-corrected when it found information gaps. It demonstrated the full potential of the agent paradigm -- and also exposed early problems like infinite loops and massive token consumption.
