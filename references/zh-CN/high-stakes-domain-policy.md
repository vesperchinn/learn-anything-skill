# 高风险领域政策

本文档定义 Learn Anything Skill Pack 如何处理医疗、法律、金融、安全关键和职业认证等高风险领域。

## 什么是高风险领域

当错误信息可能造成身体伤害、金钱损失、法律后果、安全事故或职业资格风险时，该领域属于高风险领域。

| 类别 | 示例 | 风险 |
| --- | --- | --- |
| 医疗与健康 | 疾病、药物、治疗、心理健康、营养 | 错误信息可能影响健康或生命安全 |
| 法律与合规 | 合同、税务、劳动法、隐私法规、知识产权 | 错误信息可能造成法律责任 |
| 金融与投资 | 投资、税务、保险、会计、加密资产 | 错误信息可能造成财务损失 |
| 安全关键工程 | 航空、汽车、医疗设备、工业控制、网络安全 | 错误信息可能造成安全事故 |
| 职业认证 | 医师、律师、CPA、CFA、工程师、云认证 | 错误材料可能影响考试和职业判断 |

## 必须加入教育用途声明

如果学习领域属于高风险领域，学习仓库 README 顶部必须加入：

```markdown
> [!CAUTION]
> **仅供教育用途**
>
> 本仓库由 AI 生成，用于学习 {domain} 的基础概念和学习路径。
> 它不是医疗建议、法律建议、金融建议、安全建议或职业建议，也不能替代官方指南、合格专业人士意见或认证培训。
> 在应用任何关键结论前，请使用权威来源复核，并咨询具备资质的专业人士。
```

每个高风险模块顶部也必须加入相同或更具体的教育用途声明。

## 来源要求

高风险领域比普通领域要求更严格：

| 要求 | 普通学习资料 | 高风险学习资料 |
| --- | --- | --- |
| 最低来源层级 | 二级来源可接受 | 一级来源优先，关键主张必须一级来源 |
| 交叉验证 | 建议 | 必须 |
| 时效性 | 按风险等级复查 | 优先使用最新权威来源 |
| 专业建议 | 不建议 | 禁止 |
| 教育用途声明 | 可选 | 必须 |

优先来源包括：

- 官方指南、政府网站、监管机构文件
- 专业协会 guideline
- 同行评审论文或系统综述
- 正式教材、认证机构大纲
- 官方标准和规范

## 内容边界

允许：

- 解释概念、术语、历史背景和学习路径。
- 说明不同观点存在，但标明来源和适用范围。
- 引导学习者查阅权威资料和咨询专业人士。

禁止：

- 诊断疾病、推荐治疗、给药剂量或替代医疗建议；医疗内容应建议咨询执业医疗专业人士。
- 针对具体法律处境给出法律建议；法律内容应说明司法辖区，并建议咨询执业律师。
- 推荐具体投资、交易、税务安排或金融产品；金融内容应说明这不是金融建议，并建议咨询持牌金融顾问或合格金融专业人士。
- 忽略急救或紧急安全风险；遇到疑似紧急症状或即时危险时，应建议联系当地急救服务或合格专业人士。
- 声称安全关键代码“可生产使用”“无风险”“已完全正确”。
- 把考试材料说成保证通过。
- 在没有日期和权威来源时声明“当前法律”“最新 guideline”“最新价格”。

## 地域和适用范围

法律、医疗、税务、金融和认证内容常常受国家、地区或机构影响。

Agent 必须：

1. 明确说明适用地域或机构范围。
2. 不把某一地区规则写成全球规则。
3. 对无法确认地域的内容标记 `[未验证]`。
4. 建议学习者查阅本地官方来源。

## 高风险记录要求

高风险模块必须在 `09_sources/claims_to_verify.md` 中登记关键主张，并标记为高优先级：

```markdown
- [ ] 🔴 [高风险] {主张} — 模块：{path} — 建议验证：查阅官方 guideline / 监管文件 / 认证机构大纲
```
