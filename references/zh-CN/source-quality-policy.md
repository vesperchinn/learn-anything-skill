# 信息源质量政策

本文档定义 Learn Anything Skill Pack 如何评估信息源，目标是减少 AI 幻觉、避免伪造引用，并提升学习资料的准确性。

## 信息源层级

### 一级来源：权威原始资料

优先使用原始、权威、可核验的资料：

- 官方文档、语言规范、API reference
- 同行评审论文、正式出版的学术论文
- 大学教材、专业教材、权威手册
- 标准文件，例如 RFC、ISO、W3C specification
- 官方指南、政府法规、专业机构发布的 guideline

一级来源可信度最高，通常经过机构审核、编辑审核或同行评审。

### 二级来源：专家解释资料

二级来源用于帮助理解一级来源，但不能替代一级来源：

- 由领域专家撰写的教程
- 会议演讲、课程讲义、公开课材料
- 有明确作者和专业背景的技术博客
- 由可信机构或平台整理的课程

二级来源有解释价值，但可能带有作者观点，也可能因版本变化而过时。

### 三级来源：低可信辅助资料

三级来源只能用于启发和初步探索，不能作为事实依据：

- AI 生成内容
- 论坛回答、问答社区、评论区
- 社交媒体帖子
- 没有作者、来源或更新时间的文章

三级来源中的事实主张必须回到一级或二级来源复核后才能写成确定结论。

## 评估标准

记录或使用一个来源前，至少检查以下问题：

| 标准 | 检查问题 |
| --- | --- |
| 权威性 | 谁发布的？是否具备领域资质？ |
| 时效性 | 何时发布或更新？是否仍适用于当前版本或规则？ |
| 准确性 | 是否能被一级来源验证？ |
| 目的 | 是教育、说明、宣传、销售，还是观点表达？ |
| 交叉验证 | 是否有独立来源支持同一结论？ |

## Agent 行为规则

1. 能引用来源时必须优先引用来源。
2. 不得伪造 URL、DOI、论文标题、作者、发布日期、官方文档或 benchmark。
3. 官方文档、教材、论文优先于博客、论坛和 AI 摘要。
4. 无法核验的主张必须标记为 `[未验证]`。
5. 使用过的信息源必须记录到 `09_sources/sources.md`。
6. 如果没有联网能力，不能把具体链接、发布日期或版本号写成已验证事实。

## 信息源记录格式

在 `09_sources/sources.md` 中使用如下格式：

```markdown
| 信息源 | 类型 | 层级 | 状态 | 最后验证日期 | 备注 |
| --- | --- | --- | --- | --- | --- |
| Python 官方文档 | 官方文档 | 一级 | 已验证 | 2026-01-15 | 通过网页访问确认 |
| 某教材章节 | 教材 | 一级 | 未联网验证 | N/A | 纸质或本地资料 |
| 某专家教程 | 教程 | 二级 | 未验证 | 尚未验证 | 需要对照官方文档 |
```

## 禁止行为

- 编造看起来真实的链接、DOI 或论文。
- 猜测最新版号、发布日期、价格、考试大纲或 benchmark 分数。
- 把 AI 生成内容当作真实来源。
- 用论坛回答作为关键事实的唯一依据。
- 在没有联网验证时声称“官方文档显示”“研究表明”“数据显示”。
