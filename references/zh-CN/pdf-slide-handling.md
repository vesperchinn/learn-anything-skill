# PDF 与幻灯片处理规则

PDF 和 PPT 常包含混合内容：正文、图片、图表、表格、截图、流程图和演讲备注。Material-Grounded Learning Mode 必须记录哪些内容已可靠提取，哪些内容需要复核。

## Intake 检查清单

每个文件都要记录：

- 文件名和格式。
- 是文本型、扫描件、图片密集型还是混合型。
- 只有在确实知道时才记录页数或幻灯片数量。
- 使用的提取方式。
- 是否包含图片、表格、图表、截图或流程图。

## 提取规则

- 文本必须先提取，才能总结。
- 表格必须标记为表格，并尽量保留行列结构。
- 图表必须标记为图表；只有数值清楚可读时，才能转成数字主张。
- 截图必须标记为截图；只有可读 UI 文本才能转录。
- 流程图必须尽量保留节点、箭头和标签。
- 演讲备注不同于幻灯片正文，需要单独标记。

## 位置规则

- 只有提取工具或用户提供页码时，才能使用页码。
- 只有 deck 或导出内容提供幻灯片编号时，才能使用幻灯片编号。
- 如果位置未知，写 `location unresolved`，不得猜测。

## 视觉元素标签

在 `material_index.md` 中使用：

- `visual: chart`
- `visual: table`
- `visual: screenshot`
- `visual: flowchart`
- `visual: diagram`
- `visual: unreadable`

## 未解决问题

需要记录的问题包括：

- 扫描 PDF 没有 OCR
- 图片型幻灯片
- 图表标签不可读
- 表格解析失败
- 演讲备注缺失
- 页码或幻灯片顺序不明确

依赖这些内容的学习模块必须标记为 `Partially grounded`，直到问题解决。
