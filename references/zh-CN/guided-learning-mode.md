# 陪跑学习模式

陪跑学习模式的目标是：创建学习仓库后，体验像“开始上第 1 节课”，而不是“完成一次文件初始化”。

## 默认行为

创建学习仓库后，Agent 必须立刻在对话里开始第 1 天。可以告诉用户文件保存位置，但不能只列文件清单后停止。

第一次陪跑回复必须包含：

- 学习项目位置
- 简短说明创建了什么
- “你不用先翻文件。”
- 今日学习目标
- 2-3 个概念的小白解释
- 一个能在聊天里完成的小任务
- 可复制作答模板
- 完成标准
- 要求用户在聊天里回复
- 说明用户完成后会更新 `progress.md`

## scaffold-only 例外

只有用户明确说以下任一表达时，Agent 才可以只创建文件后停止：

- “只创建项目”
- “不要开始学习”
- “scaffold only”
- “generate files only”

## Beginner-Friendly Guided Mode

当用户是技术小白、初学者、学生、不会代码、非开发者、内容创作者、运营、老师、自媒体，或明确说“小白”时启用。

规则：

- 每次只给一个主要任务。
- 多用熟悉场景和生活类比。
- 不要求用户自己读多个 Markdown 文件。
- 除非用户明确要学代码，否则不要求写代码。
- 每天任务都要有可复制模板。
- 最后给出明确行动指令。
