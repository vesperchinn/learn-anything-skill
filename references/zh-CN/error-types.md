# 错误类型诊断参考

如何分类和纠正学习者的错误。供 `core/prompts/error-diagnosis.md` 和 `stage-test.md` 使用。

## 四种错误类型

### 1. 不懂概念 `[concept-gap]`

**定义**：学习者不知道这个概念是什么意思。无法定义、识别，也无法将其与不相关的概念区分开来。

**识别信号**：
- 空白回应或"我不知道"
- 定义完全错误
- 无法回答基础回忆题（如"什么是 X？"）

**补救策略**：
1. 回到 `01_core_concepts/` 中的概念定义
2. 用费曼技巧重新解释——更简单的语言、具体的类比
3. 出 3 道回忆题确认基本理解
4. 在回忆掌握牢固之前，**不要**进入应用环节

**示例**：
> 学习者："Embedding 就是……一种数据库？"
> → 不懂概念。学习者完全不知道 embedding 是什么。

**教学流程**：
```
解释（用最简单的语言说清楚）
  ↓
示例（给 2-3 个直观例子）
  ↓
练习（3 道回忆题）
  ↓
检查（确认回答正确）
  ↓
复盘（总结一句话，巩固认知）
```

---

### 2. 不会应用 `[application-failure]`

**定义**：学习者能正确定义概念，但不知道如何用它来解决问题。知道"是什么"，但不知道"怎么用"。

**识别信号**：
- 定义正确，应用错误
- "我知道它是什么，但不知道怎么用它来解决这个问题"
- 能回答回忆题，但场景题不会

**补救策略**：
1. 展示一个应用该概念的完整示例
2. 给一个高度相似的场景，只做微小变化
3. 让学习者模仿示例中的模式
4. 逐步增加与示例的差异度

**示例**：
> 学习者能正确定义"agent 中的 tool use"，但不会写代码定义工具。
> → 不会应用。

**教学流程**：
```
解释（回忆概念定义，建立连接）
  ↓
示例（展示一个完整的工作示例）
  ↓
练习（给一个高度相似的场景让学习者模仿）
  ↓
检查（验证输出是否正确）
  ↓
复盘（对比示例与练习的异同）
```

---

### 3. 表达不清 `[expression-unclear]`

**定义**：学习者理解了概念，但无法清晰地表达出来。解释模糊、循环定义，或用术语本身来解释术语。

**识别信号**：
- "就是那个……你知道的……就是……"
- 循环定义（如"Agent 就是能像 agent 一样行动的东西"）
- 堆砌技术术语但说不出实际含义
- 能解决问题但说不出为什么

**补救策略**：
1. 让学习者向特定听众解释（如"给一个 12 岁的小孩解释"）
2. 要求使用具体类比，不准使用抽象术语
3. 写下来再复盘（不只靠口头表达）
4. 找出解释中哪里卡住了
5. 重复直到解释清晰、简洁、有类比支撑

**示例**：
> 学习者："ReAct 就是……一种 agent 先思考再行动的模式。它是一个推理-行动的循环。它对 agent 很有用。"
> → 表达不清。循环解释、没有具体例子、模糊不清。

**教学流程**：
```
解释（学习者用自己的话讲一遍）
  ↓
示例（要求用一个具体类比）
  ↓
练习（让学习者写下来，不是口头说）
  ↓
检查（指出解释中模糊或不准确的地方）
  ↓
复盘（总结出最清晰的一句话版本）
```

---

### 4. 知识混淆 `[knowledge-confusion]`

**定义**：学习者混淆了两个或多个相关概念。单独理解每个概念没问题，但分不清它们之间的边界。

**识别信号**：
- "这个跟 X 不是一回事吗？"
- 把含义不同的术语混用
- 答非所问——把概念 A 的逻辑用到了概念 B 的问题上

**补救策略**：
1. 制作一个逐项对比的对照表
2. 突出关键区别——一句话说清楚"分水岭"在哪
3. 给成对示例："这是 X 因为……这是 Y 因为……"
4. 辨别练习：给出 5 个案例，让学习者判断每个属于 X 还是 Y

**示例**：
> 学习者把"微调（fine-tuning）"和"RAG"混为一谈。
> → 知识混淆。虽然都是给 LLM 增加知识的方式，但原理完全不同。

**教学流程**：
```
解释（分别定义两个概念，说清楚各自的核心）
  ↓
示例（做一个并列对比表）
  ↓
练习（给出混淆案例，让学习者辨析）
  ↓
检查（逐一验证判断是否正确）
  ↓
复盘（用一句话总结区分的本质）
```

## 诊断决策树

```
学习者犯了错误
│
├─ 能定义这个概念吗？
│   不能 → [concept-gap] 不懂概念
│   能 → 继续
│
├─ 能用它解决问题吗？
│   不能 → [application-failure] 不会应用
│   能 → 继续
│
├─ 能清晰解释它吗？
│   不能 → [expression-unclear] 表达不清
│   能 → 继续
│
└─ 是否把它和另一个概念搞混了？
    是 → [knowledge-confusion] 知识混淆
    否 → 这可能只是一个粗心失误——记录下来，但不要过度归因
```
