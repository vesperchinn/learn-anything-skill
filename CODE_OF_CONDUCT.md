# Code of Conduct

## Our Pledge

We want Learn Anything Skill Pack to be useful, respectful, and accessible to
contributors across languages, platforms, and experience levels.

Participants are expected to:

- be respectful in issues, discussions, and pull requests
- give clear feedback without personal attacks
- credit sources and prior work when contributing examples or documentation
- avoid sharing private user materials, credentials, or copyrighted files that
  cannot be redistributed

## Unacceptable Behavior

Unacceptable behavior includes harassment, threats, hate speech, deliberate
misinformation, exposing private information, or repeatedly disrupting project
discussion.

## Enforcement

Maintainers may edit, hide, or remove comments, issues, pull requests, or other
contributions that violate this code. Repeated or severe violations may lead to
temporary or permanent loss of participation privileges.

## Attribution

This code is intentionally short and project-specific, with principles adapted
from common open source community standards.
