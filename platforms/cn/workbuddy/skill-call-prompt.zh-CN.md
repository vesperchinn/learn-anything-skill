# WorkBuddy Skill Call Prompt

当用户提出“帮我学习某个领域”“基于这些资料做学习计划”“把课程资料整理成学习任务”“输出阶段学习报告”等需求时，调用 Learn Anything 办公任务 Skill。

## 调用目标

把用户输入或上传文件转成可执行学习任务和可交付报告：

- 学习目标澄清
- 资料登记与提取
- 知识地图
- 阶段学习计划
- 每日练习与输出任务
- 阶段测试
- 错因分析
- 来源与时效检查
- 最终报告

## 必填信息

- 学习领域
- 用户基础
- 每天可投入时间
- 学习周期
- 学习目标
- 最终交付物
- 是否有资料
- 是否允许联网核查

## 输出要求

WorkBuddy 输出应像办公交付物，而不是聊天记录。每次任务应有标题、结论、任务表、风险说明和下一步。
