# WorkBuddy File Processing Rules

## 文件登记

每个上传文件必须记录：

- 文件 ID
- 文件名
- 文件类型
- 上传时间
- 是否可读
- 提取方式
- 是否含图片、表格、截图、流程图
- 提取问题

## 提取规则

- PDF：提取正文、目录、页码、表格和图注。
- PPT/PPTX：提取标题、正文、备注、图表和每页主题。
- Word/DOCX：提取标题层级、正文、表格、批注。
- Markdown/TXT：保留标题结构和原文段落。
- 图片/扫描件：需要 OCR；无法 OCR 时记录问题。

## Grounding 规则

- 学习内容必须引用文件 ID 和位置。
- 无法读取的内容不得被总结。
- 图表和截图必须显式标记，不能当作普通文本。
- 外部补充内容必须标记 `Supplemental`。

## 降级

如果 WorkBuddy 当前配置不能读取文件：

- 要求用户粘贴文本、提供 OCR 或转换为 Markdown/TXT。
- 可以输出“资料处理建议报告”。
- 不能输出“基于文件内容的学习总结”。
