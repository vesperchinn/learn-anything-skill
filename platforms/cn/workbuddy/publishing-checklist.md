# WorkBuddy Publishing Checklist

## 包完整性

- [ ] 已配置 Skill 调用提示词
- [ ] 已上传核心协议到知识库
- [ ] 已上传可靠性和资料 Grounding 文档
- [ ] 已配置文件处理规则
- [ ] 已配置报告输出模板
- [ ] 已配置无文件读取、无联网、无工作流降级说明

## 行为验收

- [ ] 能以办公任务 Skill 形式被调用
- [ ] 上传资料会先登记和索引
- [ ] 输出报告不是普通聊天散文
- [ ] 日常学习任务包含概念、练习、任务和验收标准
- [ ] 阶段测试不会提前给答案
- [ ] 错因分析使用四类错误标签
- [ ] 每份报告包含来源、时效和待核查项
- [ ] 不能读文件时不会假装读过
