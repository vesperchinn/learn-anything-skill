# Coze Publishing Checklist

## 配置检查

- [ ] Bot Prompt 已使用 `bot-prompt.zh-CN.md`
- [ ] 知识库已上传核心协议
- [ ] 知识库已上传可靠性和资料 Grounding 文档
- [ ] 已配置变量 schema
- [ ] 已配置长期记忆或单轮 `learning_state` 输出
- [ ] 已配置资料上传或知识库导入流程
- [ ] 已配置无文件读取、无联网、无工作流降级说明

## 行为检查

- [ ] 不依赖 `SKILL.md`
- [ ] 首轮会收集学习变量
- [ ] 日常学习包含 3 个概念、5 道练习、1 个任务
- [ ] 阶段测试不提前给答案
- [ ] 错误会先归因再讲解
- [ ] 资料学习先登记和索引资料
- [ ] 无法读取资料时不会编造内容
- [ ] 无联网时标记未验证草稿
- [ ] 每次输出包含来源、时效和待核查项
