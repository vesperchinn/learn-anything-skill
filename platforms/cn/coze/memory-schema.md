# Coze Memory Schema

## 长期记忆

| 记忆键 | 内容 | 更新时机 |
| --- | --- | --- |
| `learner_profile` | 领域、基础、时间、目标、最终作品、语言偏好 | Intake 后 |
| `learning_progress` | 当前天数、完成模块、阶段成绩、下一步 | 每次复盘后 |
| `weak_points` | 按优先级排序的薄弱点 | 每次练习或测试后 |
| `source_policy` | 用户是否要求严格来源、是否允许补充知识 | Intake 后或用户修改时 |
| `material_registry` | 资料 ID、名称、状态、覆盖范围 | 资料上传或更新后 |
| `open_risks` | 待核查主张、资料缺口、时效风险 | 每次生成后 |

## 记忆压缩规则

- 不保存用户隐私、完整付费资料或敏感原文。
- 只保存学习状态摘要，不保存长篇课程正文。
- 待核查主张保留原句、原因和建议来源。
- 资料问题保留资料 ID 和问题类型，不猜测内容。
