# Material Grounding Checklist

- [ ] User material intake exists.
- [ ] PDF/PPT handling rules exist.
- [ ] OCR or unreadable content fallback exists.
- [ ] Tables, screenshots, charts, and flowcharts are treated explicitly.
- [ ] Material manifest exists.
- [ ] Material index exists.
- [ ] Material coverage map exists.
- [ ] Extraction issues exist.
- [ ] Supplemental knowledge labeling exists.
- [ ] No fake page or slide number rule exists.
- [ ] Copyright and privacy warning exists.
