# PR Checklist

- [ ] Changed modules identified.
- [ ] Impact matrix reviewed.
- [ ] Matching locale files reviewed or intentionally unchanged.
- [ ] Evals updated or confirmed unnecessary.
- [ ] Examples updated or confirmed unnecessary.
- [ ] Platform adapters reviewed if public behavior changed.
- [ ] Reliability layer reviewed if factuality, source, freshness, or high-risk behavior changed.
- [ ] Material mode reviewed if user materials, PDF/PPT, OCR, or fallback behavior changed.
- [ ] Harness checks run.
- [ ] No generated `dist` package treated as source of truth.
