# Locale Parity Checklist

- [ ] `core/prompts/en-US` and `core/prompts/zh-CN` file names match.
- [ ] `prompts/en-US` and `prompts/zh-CN` file names match.
- [ ] `templates/en-US` and `templates/zh-CN` file names match.
- [ ] `references/en-US` and `references/zh-CN` file names match.
- [ ] `evals/en-US` and `evals/zh-CN` have matching core coverage.
- [ ] `interface_language`, `learning_language`, `material_language`, and `locale` are used consistently.
- [ ] English files do not contain obvious Chinese text.
- [ ] Chinese files are not mostly untranslated English.
